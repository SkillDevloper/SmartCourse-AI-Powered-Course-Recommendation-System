About SmartCourse

Project Overview

SmartCourse is an intelligent AI-powered course recommendation system that helps learners discover the most relevant courses based on their natural language queries. The system combines traditional keyword-based approaches with modern neural embeddings to provide accurate and context-aware recommendations.

Technical Stack

  • Backend: Flask (Python)
  • Frontend: Bootstrap 5, JavaScript
  • Database: SQLite
  • ML/NLP: scikit-learn, spaCy
  • Embeddings: Sentence Transformers
  • Similarity: Cosine Similarity
  • Vectorization: TF-IDF
  • Persistence: Joblib, Pickle

AI Models

TF-IDF Model

Approach: Keyword-based matching using TF-IDF

Strength: Great for exact keyword matches and domain-specific terms

Use Case: When queries contain specific technical terms

Neural Model

Approach: Semantic understanding using Sentence-BERT embeddings

Strength: Captures context and conceptual meaning beyond keywords

Use Case: When looking for conceptually related courses

Dataset Information

The system uses a dataset of 8,500+ courses across multiple domains:

  • Computer Science & Data Science
  • Business & Economics
  • Engineering & Mathematics
  • Science & Humanities

Each course includes title, description, department, difficulty level, rating, and university.

Evaluation Metrics

  • Precision@K: Accuracy of top K recommendations
  • Recall@K: Coverage of relevant courses in top K
  • Hit Rate: Frequency of relevant courses appearing in recommendations
